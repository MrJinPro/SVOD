## 🔍 ОСНОВНЫЕ ОТЧЁТЫ И ИХ СТРУКТУРА

### 1. **ОТЧЁТ ПО РАБОТЕ ПЦН** (Ведомость по тревогам)

**Файл:** `Отчет по работе ПЦН (все записи за сутки).xlsx`
**Листов:** 1 (`Лист1`)
**Строк:** 350 (за сутки 27.04.2026)
**Колонки (12):**

```
Дата тревоги | № Объекта | Адрес объекта | ФИО | Шлейф | Инженер | ГБР | Оператор | 
Время вызова | Время прибытия | Результат осмотра | Штраф
```

**Особенности:**

- Сортировка: по **дате/времени вызова** (по возрастанию)
- Включает ВСЕ тревоги (без ГБР, с ГБР, отзывы, открытия, снятия)
- № Объекта может быть: число, текст (B00128, B00946), NULL (у отбоев)
- Время прибытия = Время вызова, если ГБР не выезжал (NULL)
- Поле "Штраф" всегда 0 (может быть вычисляемое)

## 📍 Где встречается каждый из 6 критических вопросов

1. **Шлейф** — встречается в отчете `Отчет по работе ПЦН` в колонке `Шлейф`, а также в отчете `Отчет по сработкам шлейфа`. Требуется понять, из какого поля исходной схемы берется это значение.
2. **Инженер** — есть в `Отчет по работе ПЦН`, `Отчет по инженерам` и `Отчет по выполненным заявкам инженеров`. Но в текущей базе данных нет явного поля инженера, поэтому этот вопрос критичен.
3. **ГБР** — встречается в `Отчет по работе ПЦН` и `Отчет по выездам ГБР`. Нужен однозначный способ идентификации ГБР-выезда.
4. **Смена** — ключевой для `Отчет по смене операторов` и `Отчет по одному оператору за смену`. Требуется точный день/ночь и логика смены.
5. **Штраф** — есть в `Отчет по работе ПЦН` и `Отчет по штрафам`. Нужно понять, это вычисляемое поле или уже готовое значение в источнике.
6. **Результат осмотра** — есть в `Отчет по работе ПЦН` и, вероятно, в отчетах по выездам ГБР/инженерам. Это поле должно быть явно описано, иначе отчёт собрать невозможно.
