## 📝 ОСНОВНЫЕ ЗАПРОСЫ

### Query 1: Базовая ведомость (ПЦН)

```sql
-- Core Ledger: Event + Action + Object
SELECT
  e.timestamp AS "Дата тревоги",
  e.object_id AS "№ Объекта",
  COALESCE(o.address, e.location) AS "Адрес объекта",
  COALESCE(o.client_name, e.client_name) AS "ФИО",
  -- Шлейф из code? или zone? TBD
  CASE WHEN e.code LIKE '%[0-9]%' THEN e.code ELSE NULL END AS "Шлейф",
  -- Инженер - откуда? TBD (не в schema)
  NULL AS "Инженер",
  -- ГБР - из EventAction.gbr_name или code?
  (SELECT ea.gbr_name FROM event_actions ea 
   WHERE ea.event_id = e.id OR ea.raw_event_id = CAST(e.id AS INT) 
   ORDER BY ea.action_time DESC LIMIT 1) AS "ГБР",
  -- Оператор - из EventAction
  (SELECT ea.operator_name FROM event_actions ea
   WHERE ea.event_id = e.id OR ea.raw_event_id = CAST(e.id AS INT)
   ORDER BY ea.action_time DESC LIMIT 1) AS "Оператор",
  e.timestamp AS "Время вызова",
  -- Время прибытия = последний action_time?
  (SELECT MAX(ea.action_time) FROM event_actions ea
   WHERE ea.event_id = e.id OR ea.raw_event_id = CAST(e.id AS INT)) AS "Время прибытия",
  e.result_text AS "Результат осмотра",
  0 AS "Штраф"  -- TBD: как вычисляется?
FROM events e
LEFT JOIN objects o ON e.object_id = o.id
WHERE e.type = 'alarm'
  AND NOT (e.code LIKE 'Z%' OR (e.code_group >= 8 AND e.code_group <= 99))  -- Исключения
ORDER BY e.timestamp ASC
```

### Query 6: Статистика по оператору

```sql
SELECT
  ea.operator_name AS "Оператор",
  COUNT(DISTINCT e.id) AS "Кол-во тревог",
  COUNT(DISTINCT CASE WHEN ea.gbr_name IS NOT NULL THEN e.id END) AS "Выезды ГБР",
  COUNT(DISTINCT DATE(e.timestamp)) AS "Дни работы",
  MIN(e.timestamp) AS "Первая тревога",
  MAX(e.timestamp) AS "Последняя тревога"
FROM events e
JOIN event_actions ea ON e.id = ea.event_id OR CAST(e.id AS INT) = ea.raw_event_id
WHERE DATE(e.timestamp) = DATE('2026-04-27')
GROUP BY ea.operator_name
ORDER BY COUNT(DISTINCT e.id) DESC
```

```
Возможные варианты:
```

### 3️⃣ **ГБР (Group Response Brigade)**
```
В archive: нет поля GBR
В eventservice: есть GrResponseName (текстовое имя группы)
В Event/EventAction: есть gbr_name (текстовое)
Вопросы:
- Это групп НА ВЫЗОВ (кто отреагировал)?
```

### 4️⃣ **Smena (Смена) / Shift**

```python
    __tablename__ = "engineers"
    id: Mapped[str] = mapped_column(String(64), primary_key=True)
    name: Mapped[str] = mapped_column(String(255), index=True)
    status: Mapped[str] = mapped_column(String(16), default="active")

class GroupResponse(Base):
    __tablename__ = "group_responses"
    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    name: Mapped[str] = mapped_column(String(255), index=True)
    code: Mapped[str | None] = mapped_column(String(16), nullable=True)
    
class Shift(Base):
    __tablename__ = "shifts"
    id: Mapped[str] = mapped_column(String(36), primary_key=True)
    name: Mapped[str] = mapped_column(String(64))  # "день", "ночь"
    start_time: Mapped[time_type] = mapped_column(Time)
    end_time: Mapped[time_type] = mapped_column(Time)
```
